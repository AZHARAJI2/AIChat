# 🧠 مشروع تحليل المحادثات بالذكاء الاصطناعي (AI Chat Analysis)

نظام متكامل لتحليل المحادثات العربية باستخدام نماذج تعلم الآلة (NLP)، يهدف إلى استخراج المواضيع، تحديد نوع الشخصية، وقياس مستوى التعقيد في الأسئلة والمحادثات.

## 🌟 المميزات

- **تحليل المواضيع (Topic Modeling):** تصنيف الأسئلة إلى (تقني، أكاديمي، صحي، أعمال، إلخ).
- **تحليل الشخصية (Persona Analysis):** تحديد طبيعة السائل (متعلم، منجز، مستكشف، حلّال مشاكل).
- **مستوى التعقيد:** قياس مدى صعوبة وعمق السؤال.
- **واجهة تفاعلية (Dashboard):** لوحة تحكم متطورة باستخدام Streamlit لعرض النتائج والرسوم البيانية.
- **RESTful API:** واجهة برمجة تطبيقات جاهزة باستخدام FastAPI.
- **التحقق الصارم من المدخلات:** قبول النصوص العربية فقط، رفض الأرقام والحروف الإنجليزية.
- **التحقق من صحة الملفات:** التأكد من أن الملفات المرفوعة تحتوي على محادثات عربية صالحة.

## 📂 هيكلية المشروع

```bash
AIChat/
├── backend/            # كود السيرفر (API)
│   ├── api.py          # نقاط النهاية (Endpoints)
│   ├── services.py     # منطق الربط

│   ├── profile_generator.py # المحرك الرئيسي للتحليل

│   └── dashboard.py    # تطبيق لوحة التحكم

```

## 🚀 طريقة التشغيل

### 1. تثبيت المتطلبات
تأكد من وجود Python مثبتاً، ثم قم بتثبيت المكتبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل لوحة التحكم (Frontend)
لفتح الواجهة الرسومية التفاعلية:
```bash
streamlit run projc/dashboard.py
```
ستفتح الصفحة تلقائياً في المتصفح. يمكنك كتابة سؤال مباشرة أو رفع ملف JSON يحتوي على محادثات.

### 3. تشغيل السيرفر (Backend API)
إذا كنت تريد استخدام النظام كـ API لمشروع آخر:
```bash
uvicorn backend.api:app --reload
```
رابط التوثيق التلقائي (Swagger): `http://127.0.0.1:8000/docs`

## 🔒 قيود المدخلات

### النصوص المباشرة
النظام **يقبل النصوص المختلطة** (عربي مع أرقام أو إنجليزي) طالما يحتوي النص على **نسبة كافية من اللغة العربية**.

**شروط القبول:**
- ✅ يجب أن يحتوي النص على حروف عربية
- ✅ يجب أن يكون 30% على الأقل من الأحرف عربية
- ✅ يمكن أن يحتوي على أرقام أو كلمات إنجليزية

**أمثلة صحيحة:**
- ✅ "كيف أتعلم البرمجة؟"
- ✅ "ما هو الذكاء الاصطناعي؟"
- ✅ "اشرح لي مفهوم التعلم الآلي"
- ✅ "كيف أتعلم Python في 30 يوم" (مختلط)
- ✅ "ما الفرق بين React و Vue" (مختلط)

**أمثلة خاطئة:**
- ❌ "How to learn programming" (إنجليزي فقط)
- ❌ "123456" (أرقام فقط)
- ❌ "ما Python" (نسبة العربي قليلة جداً)

### الملفات المرفوعة
النظام **يقبل الملفات المختلطة** (عربي وإنجليزي) ويستخرج فقط النصوص العربية الصالحة للتحليل.

**شروط القبول:**
- ✅ يجب أن يحتوي الملف على **3 محادثات عربية صالحة على الأقل**
- ✅ يمكن أن يحتوي الملف على نصوص إنجليزية أو أرقام (سيتم تجاهلها)
- ✅ يجب أن تكون النصوص العربية على شكل محادثات (أسئلة وحوارات)

**يرفض النظام:**
- ❌ الملفات الفارغة
- ❌ الملفات التي تحتوي على أقل من 3 نصوص عربية صالحة

**الصيغ المدعومة:**
- JSON (مثال: `[{"prompts_ar": ["سؤال 1", "سؤال 2"]}]`)
- TXT (سطر لكل سؤال)
- CSV (عمود يحتوي على النصوص)
- Excel (.xlsx, .xls)
